# Лента новостей

Учебное React-приложение для просмотра публикаций из [DummyJSON](https://dummyjson.com/posts).

## Запуск проекта

Требуется установленный Node.js и npm.

```bash
npm install
npm run dev
```

Для проверки production-сборки:

```bash
npm run build
npm run preview
```

## Возможности

- Загружает публикации через `fetch`.
- Показывает заголовок, текст, теги, просмотры и реакции.
- Выводит посты с помощью `.map()`.
- Загружает по 10 публикаций за раз: следующую порцию можно получить кнопкой «Загрузить ещё».
- Позволяет отфильтровать загруженные публикации по тегу.
- Показывает состояние загрузки и сообщение об ошибке с возможностью повторить запрос.
- Поддерживает мобильные экраны.

## Стек

- React 18
- TypeScript
- Vite
- DummyJSON Posts API
